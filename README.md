## Задание

Реализовать отрисовку треугольника Серпинского. Центральная часть исходного треугольника исключается так, чтобы образовались три подобных треугольника; процесс рекурсивно повторяется. Пользователь должен иметь возможность установить максимальное количество итераций.

## Возможности

- рекурсивное построение треугольника Серпинского;
- выбор числа итераций от 0 до 8;
- автоматическая перерисовка при изменении итераций;
- адаптация рисунка к размеру окна;
- отдельные модель, отрисовщик и элементы управления;
- модульные тесты математической части.

## Алгоритм

Для треугольника с вершинами `A`, `B`, `C` вычисляются середины сторон `AB`, `BC`, `CA`. Центральный треугольник не рисуется, а алгоритм вызывается рекурсивно для трех угловых треугольников. При достижении глубины 0 текущий треугольник добавляется в результат.

Количество конечных треугольников после `n` итераций равно `3^n`.

## Требования

- Python 3.10+
- `tkinter` (входит в стандартную поставку Python при наличии Tcl/Tk)
- сторонние pip-зависимости отсутствуют

Проверка tkinter:

```bash
python -m tkinter
```

## Установка и запуск

```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd sierpinski_triangle
python -m venv venv
```

Windows:

```bash
venv\Scripts\activate
```

Linux/macOS:

```bash
source venv/bin/activate
```

Далее:

```bash
pip install -r requirements.txt
python main.py
```

> По требованиям преподавателя папка `venv/` намеренно не добавлена в `.gitignore`.

## Управление

Слайдер **«Итерации»** задает глубину рекурсии от 0 до 8. Значение применяется сразу, и изображение перестраивается.

## Тестирование

```bash
python -m unittest discover -s tests -v
```

Тесты проверяют вычисление середины отрезка, количество треугольников на разных глубинах и корректность координат результата.

## Архитектура

`SierpinskiModel` выполняет только математические расчеты и не зависит от GUI. `TriangleRenderer` рисует готовые треугольники на `Canvas`. `Controls` отвечает за выбор количества итераций. `SierpinskiApp` объединяет компоненты приложения.
